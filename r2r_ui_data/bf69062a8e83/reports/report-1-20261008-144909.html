Finding 05 · privesc-diff

Broken access control: 'user' reached a protected page

Affected URL
http://127.0.0.1:8911/
Severity
high
CVSS
7.5 (High) CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:N/A:N
CWE / OWASP
CWE-285 · A01:2021 Broken Access Control
Confidence
firm

Description

http://127.0.0.1:8911/admin/users is denied to anonymous users (HTTP 403) but the lower-privilege role 'user' was able to access it (HTTP 200), the same as the higher-privilege role. The server is not enforcing per-role authorization.

Business Impact

An attacker could access or manipulate sensitive data or user sessions, causing significant breach-of-trust and compliance exposure.

Proof of Concept

Anonymous GET http://127.0.0.1:8911/admin/users -> HTTP 403 (denied)
GET http://127.0.0.1:8911/admin/users as 'user' -> HTTP 200 (allowed)

Suggested Remediation

Enforce server-side authorization checks per role on this endpoint; never rely on hiding links in the UI.
