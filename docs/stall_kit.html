The analogy you open with

Most security tools
🔍 The home inspector

Walks around and hands you a checklist: this lock is weak, this window's unlatched. Useful — but it's just a list.

ReconToReport
🥷 The burglar

Opens the door, walks in, and shows you "here's the drawer I'd open, here's what I'd take" — then writes you the report. From just a web address.

After this line, people usually ask "…how?" — now they opened the technical door, not you. Let them pull you deeper; don't push.

The escalation ladder — match the person, stop where they stop

Layer 0
The walk-by
(not stopping)

Layer 1

non-techie
(most people)
The burglar analogy, then: "You give it one web address. It explores the site, logs in like a real user, and tries to reach things it shouldn't — like a customer suddenly opening the admin panel. When it gets in, it proves it and writes the report." Stop here. No "CWE", no "SQL".
Layer 2
Technical
visitor /
asks a real Q
"Its headline trick: it logs in as two users at once — an admin and a normal user — and checks whether the normal user can reach the admin's pages. A normal scanner can't do that, because it has no idea who it's logged in as. We hold both and compare." This is the line that impresses.
Layer 3
Expert /
judge grilling
you
Drop to mechanism + honest limits: everything writes to one shared store so each step attacks what the last one found; it's pre-exploitation emulation — no C2, no lateral movement, some findings need manual confirmation. (Full kit: the study guide.)
The skill is reading which layer they're on and stopping there. Over-explaining loses a layperson; under-explaining loses an expert.

Running the stall

  • Loop the demo on screen (live or a short screen-recording) — motion pulls people in.
  • One handout ready — the pitch one-pager — for "got something I can take?"
  • Poster behind you carries the detail so you never have to recite it.
  • Have the finished report open in a tab as proof, in case the live run is slow.

Your default opener

"Want the 30-second version?"

Say it to anyone who slows down. Low commitment — almost everyone says yes. Then go straight to the burglar analogy.
