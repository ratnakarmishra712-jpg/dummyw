Toolchain · one card per tool · how it works + the red-team payoff

The toolchain, tool by tool

Format: what it's for → how it works (the mechanism) → why it helps the red team.
Phase 1 · Recon
scout the target
Subdomain discoveryfinding the rest of the target's footprint
How
Feeds the main domain to passive intelligence sources — certificate-transparency logs, passive DNS, public search APIs — and collects every hostname under it. No packets hit the target; it's all third-party data.
Red team
Expands your attack surface (dev·, staging·, vpn·) before you're on anyone's radar. Staging boxes are usually softer than production — this is where the unlocked side door hides.
Web crawlermapping the live attack surface
How
Walks the site breadth-first like a browser, extracting links, script files, and forms with their input names, and saves every response body. Stays inside the authorized scope.
Red team
Gives the real target map and banks page contents, so later stages attack known endpoints instead of blind-fuzzing. Fewer requests, less noise, lower chance of tripping a WAF.
Content / directory discoveryfinding what isn't linked
How
Requests base/<word> for every entry in a wordlist and keeps the ones that resolve; anything ending in a risky extension (backup, archive, VCS metadata, env file) is flagged.
Red team
Surfaces forgotten assets — exposed .git, backup.zip, an orphaned admin panel. These left-behind files are classic high-value footholds a linked-only crawl never sees.
Phase 2 · Access
become a user
Browser login automationoperating as a real authenticated user
How
Drives a headless browser through the actual login form, then exports the live session (cookies) and keeps it, tagged with a privilege rank.
Red team
Moves you from anonymous prober to insider. Almost every meaningful web attack is post-authentication — this is the pivot from outsider knocking to user already inside.
Session / cookie importusing a credential you already hold
How
Accepts a raw session cookie and registers it as a ready identity — no login needed.
Red team
Models exactly what happens after you phish, crack, or buy a session: drop the stolen token in and immediately act as that user. Mirrors real credential-access tradecraft.
Passive traffic proxyseeing the real API underneath the UI
How
Routes browsing through an intercepting proxy and logs every request/response pair, including tokens and background API calls.
Red team
Reveals the undocumented endpoints and auth tokens the front-end actually uses — the real attack surface lives in the API, not the buttons.
Phase 3 · Scan
find the ways in
Template signature enginesweeping known, documented flaws
How
Runs a library of "send this request → match this response pattern" templates across the mapped URLs, each carrying its own severity and weakness class.
Red team
Clears low-hanging fruit fast (default creds, known CVEs, misconfigs) so human effort goes to the hard stuff — and you're never behind a conventional scanner on coverage.
Broken-access-control differentialcatching authorization that isn't enforced
How
Requests the same page three ways — anonymous, and as each privilege level you hold — and compares outcomes. A finding fires only when anonymous is denied but a low-privilege account is allowed: gated, but gated wrong.
Red team
The privilege-escalation check a signature scanner structurally can't do — it has no concept of identity. This is how a throwaway user account becomes access you shouldn't have.
Behavioral XSS checkconfirming script injection actually executes
How
Injects a unique marker into parameters, loads the page in a real browser, and watches whether it lands in the DOM unescaped or triggers script execution. Rated high only if it fired.
Red team
Gives confirmed, weaponizable XSS — not a "maybe" a defender dismisses. Confirmed client-side execution is a session-hijack / phishing primitive you build on.
Phase 4 · Exploit
prove impact
Token (JWT) analysisbreaking the site's own auth tokens
How
Pulls auth tokens from captured traffic, decodes them, and flags forgeable conditions: "no signature required," a weak/guessable signing secret, or no expiry.
Red team
A forgeable token is total auth bypass — mint one for any user, including admin. The cleanest path from "I have a token" to "I am whoever I want."
Error-based SQL injectionproving database injection with zero dependencies
How
Appends a single quote to each parameter, re-requests, and watches for a database error surfacing in the response — the classic tell that input reaches a query unsanitized.
Red team
Confirms the highest-impact web flaw (data exfiltration, sometimes RCE) and runs on any machine with nothing installed — your demo and field kit never depend on a tool being present.
Full injection engineconfirming and deepening injection
How
Points the specialist SQL-injection tool at parameterized URLs in automatic mode and records its verdict.
Red team
Goes past detection toward real exploitation — dumping schemas, extracting data — the proof that turns "possible SQLi" into an undeniable breach demonstration.
Phase 5 · Harvest & Report
loot and write-up
Secret scrapingcollecting exposed credentials from everything seen
How
Scans all captured bodies and headers for API keys, cloud keys, tokens, emails, and card numbers (card numbers checksum-validated), quarantining hits separately until a human confirms them.
Red team
The loot pass — the keys and tokens an attacker exfiltrates, often the pivot into the next system. One leaked cloud key can end the engagement in your favor.
Report generatorturning the run into an operator deliverable
How
Reads all findings from the shared store, ranks by severity, and renders impact + repro steps + remediation into a client-ready document.
Red team
The part operators hate becomes free — consistent, prioritized evidence straight out of the engagement. More time attacking, less time writing up.
The thread: every tool reads and writes one shared store, and they run in attacker order — so each tool's output becomes the next tool's input. That chaining is the capability a bag of separate tools can't reproduce.
