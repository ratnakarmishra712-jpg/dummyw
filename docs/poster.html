Abstract

Professional web testing means juggling a dozen disconnected tools and hand-stitching their output into a report. ReconToReport unifies that workflow end to end.

A Python orchestrator drives five phases, writing every discovered asset, transaction and finding into one shared data model. A browser dashboard runs scans; a templating layer renders a severity-ranked report with CVSS, impact and remediation per finding.

Method & design

  • Shared data model — targets, assets, transactions, findings, evidence, secrets, auth contexts, reports.
  • Normalization — each tool's output is parsed into one schema, so phases build on each other.
  • Authorization gate — active phases refuse to run without explicit consent.
  • Fault isolation — a failure in one phase never kills the run; per-tool time budgets prevent runaway scans.
