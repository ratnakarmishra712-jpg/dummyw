ReconToReport — Code & Data Flow

how a run moves from input → phases → shared SQLite store → report
writes to the store reads from the store green text = source file
1 · Entry & setup
CLI
recontoreport/cli.py
r2r run --url … --phases … --i-have-authorization — parses flags, resolves target.
Web UI
recontoreport/web/app.py + templates/index.html
Dashboard form → /scan builds the same config, runs in a background thread, polls /status.
Config
recontoreport/config.py
Loads YAML or from_url(); holds target, scope, phases, wordlist, nuclei, auth roles.
↓ Config object
2 · Orchestration
Orchestrator
recontoreport/orchestrator.py · phases/__init__.py
writes a targets row · resolve_phases() expands dependencies (e.g. 4 → 1,3,4) · authorization gate blocks active phases without consent · runs each phase in order with per-phase error isolation & retry policy · hands each a PhaseContext(session_factory, target_id).
↓ per phase
3 · Phases (each: shell out → capture → normalize → persist)
P1Reconcrawler · subfinder · ffuf
phases/phase1_recon.py → tools/crawler.py, tools/runner.py
writes → assets http_transactions findings
P2Traffic / Authmitmproxy · Playwright
phases/phase2_traffic.py → tools/mitm_addon.py, tools/capture.py
writes → http_transactions auth_contexts
P3Scannuclei · XSS · privesc
phases/phase3_scan.py → tools/runner.py, Playwright
reads ← assets auth_contexts http_transactions writes → findings http_transactions
P4ExploitJWT · sqlmap
phases/phase4_exploit.py → tools/jwt_analysis.py, tools/runner.py
reads ← http_transactions assets writes → findings
P5Harvestsecret scraping (offline)
phases/phase5_harvest.py → tools/secrets.py
reads ← http_transactions writes → secret_matches

4 · Reporting
Report generator
report/generator.py → report/templates/report.html.j2 (+ .xml.j2)
Groups findings by severity, renders CVSS / impact / PoC / remediation via Jinja2 → writes report-<target>-<ts>.html and a reports row. The UI serves it at /report/<run_id>.
dataflow: cli/web → config → orchestrator(targets) → P1..P5 (read/write shared SQLite) → report generator → HTML/XML
